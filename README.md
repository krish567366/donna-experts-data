# Donna Experts Data

The psychology corpus lives in [`phsycology/`](phsycology/). The directory name preserves the requested repository path.

The acquisition pipeline targets 10,000 legally redistributable scholarly documents relevant to negotiation psychology. Large original PDFs are deliberately excluded from ordinary Git history; GitHub is not suitable as the binary store for a corpus expected to occupy tens of gigabytes. Metadata, checksums, provenance, and acquisition software are versioned here.
